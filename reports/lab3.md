## 实现的功能

### spawn

- spawn用于创建一个新的进程并加载指定的程序。

- 与 fork + exec 不同，spawn 直接创建新进程并加载程序，不需要复制父进程的地址空间，因此更高效。

### stride 

- 在任务控制块中添加了 stride 和 pass 字段，用于记录进程的运行长度和步长
- 实现了 stride 调度算法，每次选择 stride 最小的进程运行，运行后增加其 stride 值
- 实现了 set_priority 系统调用，可以设置进程优先级，优先级必须 >= 2
- 进程的 pass 值计算公式为 BIG_STRIDE / priority，确保进程获得的时间片与其优先级成正比
- 在创建新进程时设置初始优先级为 16，fork 时子进程继承父进程优先级，spawn 时使用默认优先级
- 修改优先级时会重置 stride 为 0，确保公平性

步幅更新机制本质上阻止了最大步幅和最小步幅之间的差距无限增大。一个进程的步幅在一步中相对于其他进程的最大“跳跃”受其经过值。因为最大的可能的经过值是大步前进 / 2（由于优先级 >= 2），系统倾向于将步幅拉回原位，以使调度前观察到的最大差异仍然受制于这个最大可能的跳跃大小。如果差距超过了这个界限，最小步幅进程就会运行，但其步幅的增加不足以超过最大步幅，从而有效地迫使差距在后续步骤中缩小，直到落入界限之内。



```rust
use core::cmp::Ordering;

const HALF_U64_RANGE: u64 = 1 << 63;

impl PartialOrd for Stride {
  fn partial_cmp(&self, other: &Self) -> Option<Ordering> {
          // 计算差值：self - other，允许环绕
          let diff = self.0.wrapping_sub(other.0);

          // 如果差值非常大 (>= 2^63)，则表示 `self` 发生了环绕，或者在循环数轴上远小于 `other`
          if diff >= HALF_U64_RANGE {
              Some(Ordering::Less) // self is "behind" other
          } else {
              Some(Ordering::Greater) // self is "ahead" of other
          }
      }
	}
}
```
